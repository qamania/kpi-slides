# KPI · Quality Engineering · Презентації

Презентації Михайла Чуба для лекцій з інженерії якості у КПІ.

## Каталог

- [Усе працює* — Вступ у спеціальність, 26.10.2026](intro-2026/)

## Структура

```text
index.html                    # каталог презентацій
.nojekyll                     # публікація статичних файлів без Jekyll
intro-2026/
  index.html                  # інтерактивна презентація
  assets/                     # шрифти та їхні ліцензії
  materials/                  # матеріали з розділу «Джерела»
```

## Локальний перегляд

З кореня репозиторію:

```sh
python3 -m http.server 8026 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8026/.

## GitHub Pages

GitHub Pages налаштовано: **Deploy from a branch → main → /(root)**. Після коміту й push сайт оновлюється автоматично.

Адреси публікації:

- Каталог: https://qamania.github.io/kpi-slides/
- Презентація: https://qamania.github.io/kpi-slides/intro-2026/

Для Google Sites використайте **Вставити → Вбудувати** та URL потрібної презентації; перевірте навігацію й повноекранний режим у попередньому перегляді.

## Додавання презентацій

1. Створіть папку з постійною короткою назвою, наприклад `ai-testing/`.
2. Додайте до неї `index.html` та потрібні ресурси. Використовуйте відносні посилання, щоб сайт працював за шляхом `/kpi-slides/`.
3. Додайте картку з посиланням у кореневий `index.html` і запис у каталог цього README.
4. Зробіть коміт і push — GitHub Pages оновить сайт.

## Поточна презентація

Навігація: ← / → або пробіл; G — карта слайдів; S — джерела; F — повний екран; ? — довідка.

Кнопка PixelCrew на слайді 18 переходить до слайда 19 зі скріншотом основного поля та поясненням, що це локальне демо на комп’ютері викладача.

Нотатки доповідача, генератор і файли підготовки залишено в авторському workspace; тут міститься копія для публікації.
